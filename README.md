# 星際突圍 3D｜多人連線版

## 專案內容
- `index.html`：原本的單檔 HTML / Three.js 遊戲前端，保留既有遊戲內容與 iPad 觸控操作。
- `server.js`：Node.js + Express + Socket.IO 雲端多人伺服器。
- `package.json`：伺服器依賴與啟動指令。

## 本版本已接上的功能
- Socket.IO 同源連線（前端使用 `/socket.io/socket.io.js`，不需要手動填伺服器網址）。
- 私人房間六位代碼、加入房間、快速配對。
- 1v1 對戰；每房最多 2 人，全伺服器最多 8 個連線玩家（最多 4 場對戰）。
- 位置、朝向、武器、技能特效同步。
- 伺服器端射擊節流、簡易射線命中判定、傷害、死亡重生、先得 10 分勝利。
- 基本移動速度與場地邊界檢查，限制明顯瞬移。

## 本機測試
需要 Node.js 18 或更新版本：

```bash
npm install
npm start
```

瀏覽器開啟 `http://localhost:3000`。要測試 1v1，請用兩個不同瀏覽器或一台電腦加一台 iPad 開啟同一個網址。

## 雲端部署
將整個資料夾部署到支援長時間執行 Node.js、WebSocket 及自訂啟動指令的雲端服務。啟動指令為 `npm start`，平台會提供 `PORT` 環境變數。部署完成後，使用雲端服務提供的 HTTPS 網址開啟遊戲；朋友也使用同一個網址。

若要限制可連線的網站來源，可設定 `ALLOWED_ORIGIN`，多個來源以逗號分隔。正式公開前，建議再加入帳號驗證、房間閒置清理、速率限制、完整地圖障礙物遮蔽與更完整的伺服器權威物理驗證。

## 重要限制
這是可部署的多人連線 MVP，不是完整競技級反作弊版本。射擊命中目前使用伺服器端玩家膠囊近似判定；伺服器端尚未重建 HTML 中每一個 3D 地圖障礙物，因此尚未做到完整的「子彈不可穿過所有地圖牆體」驗證。前端其他單機 AI、訓練、競技玩法仍保留，但目前多人房的 1v1 是獨立對戰流程。
